Which method should I use?
Use Cin7 API Sync when:
  • You manage inventory in Cin7
  • You want real-time price updates
  • You need to sync product variants (sizes/options)
  • You want automatic matching by multiple fields
  • You update prices regularly
Use CSV Upload when:
  • You have price data in spreadsheets
  • You're making one-time or manual adjustments
  • You need to import from other systems
  • You want full control over the data format
  • You're migrating from another system

Settings Information
Box Capacity

Define how many units of each product type can fit in a standard 20kg box. These values are used to calculate the number of boxes needed for shipping and freight costs.

Shipping Rates

Configure shipping costs by rate area. Each rate area covers specific NZ regions. These rates include GST and are used for calculating freight charges in quotations. Update regularly to reflect current courier rates.

Additional Settings

Box weight limit defines the maximum weight per carton. RD surcharge is automatically added for rural delivery addresses. Both values affect final shipping cost calculations.
